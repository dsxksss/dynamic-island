# 模式配置回归验证

## 喝水历史与图表

v1.4.0 起，设置右上角「记录」展示近 90 天蓝色贡献图和每日趋势图。两种模式共用统计，仅确认喝水才加一次；悬停/键盘聚焦显示日期与次数，标签页支持左右方向键切换。

历史使用 `dynamic-island.water-history.v1` 按本地日期存储，保留旧版 `dynamic-island.water-reminder.stats.v1` 的最后一天计数，并继续同步当天计数以兼容旧版。旧版没有保存的日期显示「未记录」，不补造历史；日均值只使用有统计数据的日期。所有数据仅保存在本机。

`pnpm test` 覆盖迁移不重复累加、跨天和重载、90 天日期范围（含闰日与跨年）、无效存储降级。Vite 启动后运行 `node tests/history.browser.cjs` 验证 90 个格子、悬停次数、键盘 Tab 切换、趋势点位、完整七行布局，以及实际提醒确认后的持久化。截图使用隔离浏览器的测试数据，不写入桌面应用记录。

## 自由定位与面板展开

v1.3.4 起，设置、消息和提醒展开时按可见面板的实际大小校正屏幕边界。使用展开前胶囊所在显示器，按当前 DPI 换算物理坐标，底部避开任务栏。只移动溢出的距离，保持原有吸附范围；原生拖动中暂停校正，释放后重新同步。窗口移动仍沿用现有位置保存逻辑。

`cargo test --lib` 覆盖右侧关闭按钮位置、四边与角落、负坐标显示器、125% / 150% 缩放及透明宿主部分出屏时的自由定位。启动 Vite 后运行 `node tests/placement.browser.cjs` 检查设置展开/关闭、拖动/释放与隐藏状态的 IPC 同步。浏览器模拟 IPC，不能替代 Windows 原生拖动和跨屏的人工验收。

## 免安装版启动与升级

v1.3.2 起，首次成功启动新 EXE 会把本应用已有的开机自启项更新为当前 EXE 的完整路径，并正确引用带空格的路径。没有启用自启时不会新增自启项；任务管理器禁用状态保持不变。新文件必须先手动启动一次，移动文件后也应重新运行，以更新路径。

另一个位置的灵动岛正在运行时，启动前会显示双方版本与路径，确认后请求原程序正常关闭；取消会保留原程序。原程序未退出时会提示托盘退出后重试，不强制终止。检测到正在运行的更新版本则退出较旧的启动程序。相同 EXE 再次打开会唤起已有实例。自启触发的重复启动保持安静。

Rust 测试覆盖路径引用、版本比较、自启防降级、隔离注册表项迁移、进程路径读取和隐藏测试窗口的正常关闭。测试不操作真实启动项或用户正在运行的灵动岛；完整的用户确认/取消流程仍应在真实升级场景验收。

## 双配置

普通和游戏配置分别保存喝水提醒、弹窗、音效和系统消息开关。固定位置是通用设置。首次运行会把旧提醒设置复制到两套配置；自动切换默认关闭。

设置页的配置标签只选择编辑对象。游戏模式开关直接切换生效配置，同时关闭自动切换。开启自动切换后，前台窗口持续全屏约 1.5 秒进入游戏模式，退出全屏恢复普通模式。灵动岛自己的设置窗口不会触发退出。

真正切换配置时会停止当前提醒和循环音，按新配置重新计时；编辑未启用的配置不会重置当前计时。原来的循环提示音行为保持不变。

验证命令：

```powershell
node --test tests/profiles.test.cjs
# src-tauri 目录
cargo test --lib
```

浏览器集成验证先在仓库启动 `pnpm dev`，再运行：

```powershell
# PLAYWRIGHT_PACKAGE 可指向已经安装的 playwright 包的绝对路径。
node tests/profiles.browser.cjs
```

集成验证在隔离的无头 Edge 会话中运行。模拟 Tauri 事件和音频计数，覆盖独立编辑、普通计时、模式动画文本、旧音效停止、只响铃、手动覆盖与重新加载。未替代真实 Windows 游戏全屏检测验收；需要在原生应用中另外检查全屏进入/退出、短暂切窗口、多显示器和全屏视频的开关行为。
